# iMeshSegNet-Reg

An experimental, independent implementation based on methods in
[Two-Stage Mesh Deep Learning for Automated Tooth Segmentation and Landmark
Localization on 3D Intraoral Scans](https://doi.org/10.1109/TMI.2022.3180343)
for tooth landmark regression. This repository is not an official release
by the original paper's authors and does not imply their endorsement.

## Project status

This implementation is experimental and is provided without warranties.
No pretrained model or sample training dataset is included in this repository.
